# 读书地图（Reading Maps）

将历史、人物传记、漫画和文学作品中的地点映射到现实地理，并积累可长期维护的专题地图。

**默认流程：阅读提出地点 → ChatGPT 窗口地图即时查看与讨论 → 地望和证据经用户确认 → 原位更新 Google Drive 中该作品唯一正式 KMZ → 继续下一个地点。** Google My Maps / Google Earth 按需导入展示，不需要每次讨论时反复操作。

## 数据及发布边界

- Google Drive「读书地图｜历史地理阅读项目」是正式 KMZ 主档所在地；GitHub 存放 SOP 和可版本化的工作规范。
- ChatGPT 窗口地图是当前讨论的可视化，不是永久数据资产；更新 KMZ 并不会自动更新 My Maps。
- 历史地望的可靠度、人物亲历证据与路线精度分别记录；未知或争议地点不得以精确地标伪装。
- 「地理收藏」由用户逐项授权，独立于 KMZ、My Maps 和研究档案。
